# Chat Below for Twitch

[English](#english) · [Deutsch](#deutsch)

## English

Browser extension for Chrome and Edge (Manifest V3) that moves the Twitch chat below the video with one click.
Useful when the monitor is split into two or three windows side by side.

### Features
- Toggle via the button in the player bar, the toolbar icon or the shortcut Alt+Shift+C
- The video uses the full window width, the chat fills the space below it
- The setting is remembered and synced across tabs and devices
- No tracking, no external requests; only the `storage` permission is used

### Install (development)
1. Open `chrome://extensions` (Edge: `edge://extensions`)
2. Enable "Developer mode"
3. Click "Load unpacked" and select this folder

## Deutsch

Browser-Erweiterung für Chrome und Edge (Manifest V3), die den Twitch-Chat per Klick unter das Video verschiebt.
Praktisch, wenn der Monitor in zwei oder drei Fenster nebeneinander aufgeteilt ist.

### Funktionen
- Umschalten über den Button in der Player-Leiste, das Symbol in der Symbolleiste oder das Tastenkürzel Alt+Umschalt+C
- Das Video nutzt die volle Fensterbreite, der Chat füllt den Platz darunter
- Die Einstellung bleibt gespeichert und wird zwischen Tabs und Geräten synchronisiert
- Kein Tracking, keine externen Anfragen; nur die Berechtigung `storage` wird genutzt

### Installation (Entwicklung)
1. `chrome://extensions` öffnen (Edge: `edge://extensions`)
2. „Entwicklermodus“ aktivieren
3. „Entpackte Erweiterung laden“ und diesen Ordner auswählen
